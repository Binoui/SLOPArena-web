`tmp/patch-clip-concept-20261018/captures/runs/11-landscape-01/0102.jpg` in the game

`client/Unity/Assets/Resources/UI/Portraits/` on 21 October 2026. Keep the
English and French alt text in `src/data/fighters.ts` and `src/views/Home.astro`
aligned when replacing a shot.
