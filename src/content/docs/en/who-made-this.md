## Hi!

I'm Binoui, the dev behind SLOPArena. I work as a software engineer and I saw what AI could do first hand. In early 2026, I decided to use it to learn gamedev and make the game I've always wanted to play. I figured if I could create a solid base and make it free and open source, I would be able to find people to burn tokens with me to create the best game ever.

Creating SLOPArena has been an amazing experience, full of learnings and discoveries. The [repository ↗](https://github.com/Binoui/SLOPArena) contains all those experiments, thoughts, decisions and plenty of documentation about the process itself. Oh, and there's also basically the whole game, playable on Steam! If you're curious I suggest browsing it with an agent, they love it in here. Thanks a lot!

## What I've made so far

The first commit is from 26 May 2026. Since then the repository has grown to more than 750 commits, and the game has:

- [seven fighters](../../fighters/), three of them still being built,
- seven PvP stages,
- online rooms for up to four players, plus couch modes on one screen,
- a free playtest on Steam and a [demo that runs in the browser](/demo).

## How I work

I'm the only person on the project. AI agents write a lot of the code and docs and help make the art. I decide what gets built, review it and play it. A move isn't done because its tests pass. It's done when it feels right in a match.

A lot of my time goes into tools that make that loop faster and safer. Ability Lab lets me edit a move as data and run it through the same simulation the server uses. A gateway in front of Unity lets several agents share one Editor without stepping on each other. I write those up as I go:

- [How SLOPArena is made](../how-its-made/), the whole loop from idea to playtest build.
- [Making Nyx](../making-nyx/), a fighter built in one day, with the tools behind it.
- [Making the slop #1: Ability Lab](../making-the-slop-ability-lab/), the first episode of a series about those tools.
